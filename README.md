# 🐝 QuizBee

QuizBee is a Telegram Mini App built around competitive trivia,
prediction, psychology, puzzles and elimination games.

## 📺 Watch Ads

Players can watch verified advertisements and earn QuizBee Points.

Development mode currently contains a mock advertisement completion system.

Production advertisement verification will be connected later.

## 💰 QuizBee Points

Nigeria:

₦100 = 100 QuizBee Points

International:

$1 = 1,000 QuizBee Points

QuizBee Points are used to enter games and cannot be withdrawn.

## 🏆 Prize Balance

Competition winnings are stored separately from QuizBee Points.

Prize Balance can eventually be withdrawn.
