# 🐝 QuizBee

QuizBee is a Telegram Mini App for competitive trivia, puzzles and games.

## Initial Games

- 🎯 Guess It
- 🕵️ Who Am I?
- 💀 Impossible Question

## Wallet

QuizBee uses two separate balances:

### QuizBee Points

Used to enter games.

- Nigeria: ₦100 = 100 points
- International: $1 = 1,000 points

QuizBee Points cannot be withdrawn.

### Prize Balance

Contains competition winnings.

Prize Balance can be withdrawn.
