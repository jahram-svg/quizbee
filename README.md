# 🐝 QuizBee

QuizBee is a Telegram Mini App built around competitive trivia,
prediction, psychology, puzzles, elimination games and reward-based
competition.

## 💰 QuizBee Points

QuizBee Points are used to enter games.

They are separate from Prize Balance and cannot be withdrawn.

Current point purchase structure:

- ₦100 = 50 QuizBee Points
- $1 = 500 QuizBee Points

---

## 🏆 Prize Balance

Competition winnings are stored separately from QuizBee Points.

Prize Balance is the withdrawable reward balance.

---

## 📺 Rewarded Ads

QuizBee uses a rewarded advertising provider to allow users to earn
QuizBee Points through completed advertisements.

Ad sessions and rewards are verified server-side.

Daily advertising limits are configurable from the Admin Panel.

---

## 💳 Funding

QuizBee includes a dedicated Funding Bot for purchasing QuizBee Points.

Users can submit:

- NGN payment receipts
- USDT payment receipts

Point purchases are reviewed through the Admin Panel before points
are credited.

---

## 💸 Withdrawals

Users can request withdrawals from their Prize Balance.

Withdrawals are reviewed and processed through the Admin Panel.

Withdrawal operations use server-side transaction protections to
prevent duplicate processing and incorrect balance changes.

---

## 🎟️ Raffle

QuizBee includes a weekly raffle system with:

- Ticket purchasing
- Multiple tickets per user
- Configurable start/end time
- Ticket search
- Ticket deletion
- Winner drawing
- Winner announcement
- Global enable/disable controls

---

## 👥 Referrals & Streaks

QuizBee tracks referral attribution and player streaks.

Referral attribution uses Telegram Mini App start parameters.

Streaks are based on successful game participation.

## 🔐 Security

QuizBee includes:

- Telegram Mini App authentication

- Admin authentication
- Blocked-user protection
- Transaction-based financial operations
- Idempotent prize settlement
- Idempotent advertising rewards
- Duplicate purchase protection
- Duplicate withdrawal protection
- Competition answer transaction protection
- Request size limits
- Security response headers
- Maintenance mode
- Maintenance test-user bypass
- Online presence monitoring
